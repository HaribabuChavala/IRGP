1. Get the application URL by running these commands after install:

    kubectl get svc -n {{ .Values.namespace | default "default" }}

2. To install the chart:

    helm upgrade --install report-platform ./report-platform -n {{ .Values.namespace | default "report-platform" }} --create-namespace

3. To uninstall:

    helm uninstall report-platform -n {{ .Values.namespace | default "report-platform" }}
